# Local input bindings and non-equipment items

Verified 2026-10-27.

The input reader merges Config/PersistedSettings.json, Config/game.cfg and Config/input.ini in modification-time order. Only local files inside the detected League install are read. No input settings are modified.

Game.cfg / HUD / Movement Mode selects the profile: 0 is mouse and 1 is WASD. CameraModeWASD is a camera preference and does not select the movement profile. Mouse reads GameEvents/evtCastAvatarSpell1 and 2; WASD reads WASD/CastAvatarSpell1 and 2 (also accepting the evt-prefixed form). Explicit bindings, modifiers and unbound values take priority. Riot documents Q/F as independent WASD defaults; these are used only after positive WASD mode detection. Unknown dual-profile selections produce no displayed key. Older mouse-only files retain support for their explicit GameEvents bindings.

Reference: https://support.riotgames.com/en-us/league-of-legends/gameplay/league-of-legends-keyboard-wasd-input-faq

The shown Flash slot still comes from stored matches; the key label comes from the current global input profile, not a historical per-match keyboard recording. Champion-specific input overrides are not inferred. Cached profiles generated by the legacy reader are hidden until refreshed with spellBindingVersion 2.

Final equipment excludes both original Poro-Snax (2052) and the new 2026 disco-ball Poro-Snax (220013). The latter matches the bag in the reported screenshot. 321 was its appearance count, not an item ID. The same exclusion is applied to metrics, UI and PNG; raw match inventories are not deleted.

Item metadata and original icon paths: docs/non-equipment-items.json, from https://raw.communitydragon.org/16.21/plugins/rcp-be-lol-game-data/global/default/v1/items.json

Challenge coverage is audited against all non-capstone 101xxx entries in the pinned official client metadata: 21 challenge IDs, each with nine tier PNGs. The manifest records every URL and SHA-256 hash; tests compare the catalog with that source ID list.
