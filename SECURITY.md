# Security

Do not post live credentials, lockfiles, raw matches, player identifiers or databases in public issues. Contact the repository owner privately through an available GitHub contact; no dedicated security email is configured.

LCU access is read-only and loopback-only. Public downloads retain TLS validation. Never expose the dashboard through a tunnel or public bind address. Anonymous mode changes display labels, not the private SQLite database. Portable Node is verified against official SHA-256 checksums. Inspect the bootstrap before executing it from a fork.
