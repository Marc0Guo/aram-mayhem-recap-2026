# Contributing

Start with AGENTS.md. Use small changes, synthetic or sanitized fixtures, and Chinese/English UI labels. Run typecheck, lint, tests and build. Inspect anonymous PNG output for identity leaks. Describe the trigger, resulting behavior and validation in PRs. Keep dependency versions and pnpm-lock.yaml consistent.

Do not upload League lockfiles, credentials, databases, raw real matches, player identifiers, private screenshots or work/. Enable anonymous mode before sharing a recap; avatars and stats remain visible.
